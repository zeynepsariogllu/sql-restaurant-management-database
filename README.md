# Restaurant Database Management System

## Overview

This project was developed using Microsoft SQL Server and T-SQL to demonstrate database design, data manipulation, and querying techniques in a restaurant management scenario.

The database manages restaurant and reservation information while implementing various SQL concepts and operations.

## Features

* Restaurant and reservation database design
* CRUD operations (Create, Read, Update, Delete)
* Table modification using ALTER TABLE
* Data filtering and sorting
* Aggregate functions and grouping
* SQL JOIN operations
* Subqueries
* Views
* String functions

## SQL Concepts Implemented

### Database Operations

* CREATE TABLE
* ALTER TABLE
* INSERT
* UPDATE
* DELETE

### Query Operations

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING

### Joins

* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL OUTER JOIN
* CROSS JOIN

### Advanced SQL

* Subqueries
* Views
* String Functions
